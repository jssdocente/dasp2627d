# Configuración de Agentes IA (`.agents/`)

Instrucciones de contexto, normas pedagógicas y especificaciones técnicas para los asistentes de IA que ayudan a crear y mantener los apuntes de DASP. Claude Code las carga mediante `CLAUDE.md`, en la raíz del repositorio.

| Archivo | Contenido | Cuándo cambia |
| :--- | :--- | :--- |
| [`AGENTS.md`](./AGENTS.md) | Identidad del módulo, rol del agente y directrices | Rara vez |
| [`context/dasp_curriculum.md`](./context/dasp_curriculum.md) | Resultados de aprendizaje, criterios y mapa de cobertura | Al añadir contenido que cubra nuevos criterios |
| [`context/pedagogical_styleguide.md`](./context/pedagogical_styleguide.md) | Audiencia, tono y estructura de las páginas | Al acordar un nuevo criterio de estilo |
| [`context/mkdocs_stack.md`](./context/mkdocs_stack.md) | Sintaxis admitida, Docker, comprobaciones y despliegue | Al cambiar la infraestructura |
| [`context/referencias.md`](./context/referencias.md) | Otros materiales del módulo: qué conservar y qué superar | Al recibir nuevas referencias o completar la unidad |
| [`context/estado_apuntes.md`](./context/estado_apuntes.md) | Pendientes y erratas detectadas | Al corregir o detectar problemas |
